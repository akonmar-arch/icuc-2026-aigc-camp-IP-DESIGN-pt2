## 2026-10-12 角色设计教学调整

主课沿用原有课件顺序与案例入口，在相应知识点后接入七个实践段：

- `#character-roadmap`：人物、候选、标准、变化、交付的学习路径。
- `#reference-practice`：分离人物特征、装饰与呈现条件，并说明性格如何进入造型。
- `#candidate-review`：比较三个大形候选，先选择与说明取舍，再展开教师追问。
- `#structure-review`：从原有三视图中选一处结构，标出三个对应点。
- `#intention-practice`：从原有表情与姿势作业中选三种人物意图，隐藏说明后复核。
- `#appearance-comparison`：同一标准图的两种外观处理，先检查设计保持，再评价材质。
- `#character-homework`：两轮检查、通过或需修订的依据、下一步及过程模板下载。

原第42页的角色示例插图文件保留，页面中的指导文字更新为母版、修改目标、实际变化、意外变化与下一轮决定；不再呈现没有依据的“人工修改≥50%”判断门槛。该页面的原有 `#page-42` 锚点保留。

角色交付数量维持头像、全身、三视图、至少10个核心表情、4个姿势和2套服装。新增检查并入原有工作流程；不另设整套最终图册，也没有增加100分制或统一通过率。

`角色设计_过程与验收模板.txt` 为可填写的UTF-8文本模板。网页无需构建或新依赖，使用静态服务器即可预览。CUMI历史记录与图片、白曜原角色图均保留；新增分析与练习不冒充历史过程。
